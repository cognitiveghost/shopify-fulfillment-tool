# Phase 8.4 — Packing Tool structural migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use `superpowers:executing-plans` to
> implement this plan task-by-task, in-session. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Give `packing-tool` the same shape as `shopify-fulfillment-tool` — two packages
(`gui/` + `packing_tool/`) behind a root entry point, a onedir PyInstaller bundle, and a
`gui/assets/` pipeline with Lucide icons and Inter — without changing one pixel of what
the app renders.

**Architecture:** `git mv` the 26 flat modules in `src/` into two packages along the
GUI/backend line that the code already respects (verified: zero backend→GUI imports),
rewrite 47 import sites to absolute package paths, and delete the four `sys.path` edits
that the flat layout needed. `main.spec` gains a `COLLECT` and loses almost everything
else.

**Tech stack:** Python 3.11, PySide6, PyInstaller, pytest, ruff.

**Spec:** `shopify-fulfillment-tool/docs/superpowers/specs/2026-08-27-phase8.4-packing-structure-design.md`
**Roadmap item:** `docs/superpowers/plans/2026-08-26-phase8-roadmap.md` §2, item 8.4.

- [ ] Copy from `../shopify-fulfillment-tool/gui/assets/` into `gui/assets/`: `icons/`

- [ ] Port `gui/icons.py`, changing only its colour source: `get_theme_manager().get_current_theme().text`
      → `current_tokens().text` from `gui/theme.py`
- [ ] In `gui/theme.py`, layer the bundled family onto the tokens and stop delegating to
      `shared.theme.apply_theme` — it re-derives tokens from the theme *name*, so a layered
      font cannot reach the stylesheet through it (spec §5). Both `apply_theme` and
      `current_tokens` route through one helper:

```python
from dataclasses import replace

from shared.theme import build_palette, build_stylesheet, get_theme

from gui.fonts import load_bundled_fonts


def _tokens(theme_name: str) -> ThemeTokens:
    """shared.theme's tokens with the bundled family layered on, when available."""
    theme = get_theme(theme_name)
    family = load_bundled_fonts()
    if family is None:          # no QApplication yet, or the TTF is missing
        return theme
    return replace(theme, font_family=f"'{family}', {theme.font_family}")


def apply_theme(app: QApplication, theme: str = THEME_DARK) -> None:
    global _current
    tokens = _tokens(theme)
    app.setStyleSheet(build_stylesheet(tokens))
    app.setPalette(build_palette(tokens))
    QSettings("PackingTool", "Theme").setValue("current_theme", theme)
    _current = theme
```

  `current_tokens()` returns `_tokens(_current or <saved>)`. Keep its existing
  `ponytail:` docstring — the staleness it names is unchanged by this.
